BOOTSTRAP 引导说明（全新机器 / 已装机器接上自更新）
================================================

0) 全新机器（**还没装过 ERP**）：不需要先拿交付包，直接从通道自举装。
   前提只有一条：机器上有 Python 3.10+（Windows 用 python.org 的 3.12 x64，与包内 wheelhouse 对应）。

   **先取引导脚本，两条通道按顺序试**（国内实测 raw 常卡在 0 字节/连接被重置 —— 卡住就立刻换下一条，
   别在原地等；判断标准是"超过 45 秒没有字节"）：

   Windows（PowerShell，两条都试，哪条先成功用哪条）:
     curl.exe -fsSL --max-time 45 -o "$env:TEMP\update.ps1" "https://gh-proxy.com/https://raw.githubusercontent.com/liuyuhan180661-cell/takealot-erp-update/main/update.ps1?cb=<随机数>"
     curl.exe -fsSL --max-time 45 -o "$env:TEMP\update.ps1" "https://raw.githubusercontent.com/liuyuhan180661-cell/takealot-erp-update/main/update.ps1?cb=<随机数>"
     powershell -ExecutionPolicy Bypass -File "$env:TEMP\update.ps1"
   macOS / Linux:
     curl -fsSL --max-time 45 -o update.sh "https://gh-proxy.com/https://raw.githubusercontent.com/liuyuhan180661-cell/takealot-erp-update/main/update.sh?cb=<随机数>"
     sh update.sh

   引导脚本自己会做的事：取 update.json -> 下载整包（**逐通道试，每条 120 秒预算**，取第一个下完且
   sha256 对得上的）-> 交给新包自己的 setup（建独立 venv、离线装依赖、铺服务端与前端、起服务、跑自检）。
   装完机器上就有 erp 命令与桌面入口，以后升级：<ERP_HOME> 的 venv python 跑 server/cli.py update --check
   （同样逐通道降级）。**两条通道都取不到引导脚本时**，就让客户用交付包 zip 那套（包内 install.ps1）。

1) **自愈：装到"装依赖"那步失败**（机器上的 Python 与包内自带组件不配套 —— 真机症状：
   `No matching distribution found for pydantic-core==2.46.5`，输出里会写"离线轮子覆盖解释器 cp312
   (平台 win_amd64)，当前是 cpXXX"。Windows 装机必须是 **Python 3.12（64 位）**，32 位/3.13+/alpha 都不行）：

   ① 看现状：`python -V` 与 `python -c "import sys,sysconfig;print(sys.maxsize>2**32, sysconfig.get_platform())"`
   ② 装对的 Python（用户级、免管理员，一条）：
      `winget install --id Python.Python.3.12 --scope user --silent --accept-package-agreements --accept-source-agreements`
      （没有 winget → 让用户去 python.org 下 3.12 的 Windows installer (64-bit)，勾 Add python.exe to PATH）
   ③ 删掉上次建坏的环境（**只删 venv，别删 TakealotERP**，state 里是店铺/密钥/账本）：
      `Remove-Item -Recurse -Force "$env:LOCALAPPDATA\TakealotERPenv"`
   ④ 从通道重装（与第 0 步同一条，gh-proxy 优先）
   ⑤ 判据：最后一行必须是 `RESULT 13/13 PASS`；不是就把整段输出原样回传，别自己解释

2) 已装机器（Hermes 插件形态 / 老装机）接上自更新：
客户机上的 Hermes agent（或你自己）按下面三步走，之后就能一直自己更新：

   a) 下载更新器（三个链接哪个通就用哪个；202610082026 那段是防止 CDN 缓存压住新版本的，原样带上）
   https://raw.githubusercontent.com/liuyuhan180661-cell/takealot-erp-update/main/selfupdate.py?cb=202610082026
   https://gh-proxy.com/https://raw.githubusercontent.com/liuyuhan180661-cell/takealot-erp-update/main/selfupdate.py?cb=202610082026
   https://cdn.jsdelivr.net/gh/liuyuhan180661-cell/takealot-erp-update@main/selfupdate.py?cb=202610082026
   放到： %LOCALAPPDATA%\hermes\plugins\takealot-erp\delivery\selfupdate.py

   b) 只检查、不动文件（把所有结果念给用户）
   <Hermes venv python> "%LOCALAPPDATA%\hermes\plugins\takealot-erp\delivery\selfupdate.py" ^
       --repo liuyuhan180661-cell/takealot-erp-update

   c) 用户确认后应用（自动备份；出问题可 --rollback）
   <Hermes venv python> "...\selfupdate.py" --repo liuyuhan180661-cell/takealot-erp-update --apply

规则：先 dry-run 再 apply；校验失败一律中止；永不碰 state/；更新完跑 selfcheck.ps1 并报实际结果。
