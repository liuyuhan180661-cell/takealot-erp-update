# 退步手册（怎么安全地回到上一个好状态）

> 原则：**退步是明确动作，不是"再试一次"**。而且**默认不删任何东西**——草稿、提交、日志一律留着，
> 要删必须人确认。下面每条都写清"什么时候用 / 具体命令 / 会丢什么 / 退到什么状态算干净"。

## 1. 一条 listing 跑坏了 → 回到干净页面

| 触发 | 动作 | 会丢什么 |
|---|---|---|
| 类目点错、点反选（表单字段变 0 或字段错乱） | **硬重置**：`open_new_listing()`（内部先 `about:blank` 再回新建页）。**必须硬重置，不能"往回点"**（SPA 会保留反选状态） | 当前页未保存的一切 |
| 字段渲染成 "Unknown field" / `[data-fieldid]` 数量=0 | 先硬重置；仍 0 再 `bsk session stop --all` → 重起会话（实测字段 0→27 回来） | 会话（草稿已保存的不受影响） |
| 写值到一半发现 facts 写错 | 硬重置后**改 facts 重跑**，不要在坏页面上改 | 同上 |
| 已经点了 Save and Close（变成 Draft） | 草稿**留着**（不自动删）。截图/记录 `submission_id`，跑坏的那条在报告里标 `draft-kept` | 无 |
| 误点 Submit 且已进 In Review | **停手交人**：已提交是平台侧数据，本技能不自动撤回/下架（需要人进后台处理） | — |

**"干净状态"判据**：`新建页就绪` + 类目面板可见 + 字段数 = 该类目的预期值（如 25/27）+ `data-error` 全 false。

## 2. 环境退步（Chrome / bsk）

| 症状 | 退步动作 | 验证 |
|---|---|---|
| Chrome 点不开、没有窗口 | `pgrep -f 'Google Chrome.app/Contents/MacOS/Google Chrome'` 找**没有 `--headless`** 的那个 pid → `kill <pid>` → `open -a "Google Chrome"` | `bsk status --json` 里出现浏览器；留至少一个窗口 |
| 扩展掉线（`no browsers connected`） | 同上；扩展依赖前台有窗口 | `preflight.py` 全绿 |
| 登录态失效（被踢回登录页） | **交人登录**（本技能不碰凭据） | 页面回到 `single-product` 新建页 |

## 3. 版本退步（技能包 / 交付包）

**升级通道里同时保留了当前版和上一版**（`update.json` + `update.prev.json`），退步就靠它：

1. 看现在是什么版本：读通道里的 `update.json` → `version`（+ `released_at`）。
2. 退到上一版：用 `update.prev.json` 里记录的那个包名/指纹对应的 zip 重新安装。
3. **关键铁律：回滚必须连"版本记录"一起回滚**。只回文件不回版本记录，机器会以为自己是最新版 →
   后续更新会被**永久跳过**（这条踩过坑）。
4. 本技能自己的退步（交付方操作）：私有仓 `agent-` 的 `skills/takealot-portal-cua/` 有完整提交历史，
   `git log --oneline -- skills/takealot-portal-cua` → `git checkout <上一提交> -- skills/takealot-portal-cua/`，
   然后重新出包发版（不要手改客户机上的文件）。

## 4. 什么情况下**不许**自愈、必须交人（停手上的路）

- 登录 / 2FA / 验证码 / 短信 → 交人（本技能永不碰凭据）。
- 平台风控页（"Verify you are human"）→ 停。
- 删数据 / 下架 / 改价 / 动权限 / 撤回已提交 → 停（超出本技能范围）。
- 同一失败**重复 3 次**且没有新信息 → 停，按下面格式交证据。
- 出现"钱"或"客户数据"层面的未知状态 → 停。

## 5. 退步时必交的三样（给用户的交接格式）

1. **状态**：当前版本号、`submission_id`（提交/草稿）、当前页面 URL。
2. **证据**：报告 JSON 路径（`<TL_WORKDIR>/runs/*.report.json`）+ 关键日志片段（含时间戳）。
3. **两条方案**：**最快止血**（例如"先手工在后台补齐这一条"）与**最终定版**（例如"改 facts/引擎后重跑"），
   各一条，写清代价。

> 退步不是失败。**留下证据、说清代价、让状态可复现**，就是这条流水线要的"稳"。
